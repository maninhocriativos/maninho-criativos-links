Seu trabalho NÃO é começar do zero: é EVOLUIR esta estrutura — seja portando
para um codebase real (Next.js / Vite+React) mantendo os padrões abaixo, seja
editando os próprios arquivos do protótipo. Em ambos os casos, RESPEITE o
design system (tokens, alturas, grid de 8px) descrito aqui.

Direção visual: Linear / Vercel / Railway. Dark, profissional, UMA cor de
acento (#0070f3), SEM gradientes neon, SEM emojis, grid de 8px, fonte Poppins.

COMO RODAR O PROTÓTIPO: sirva a pasta src/ estaticamente (ex.: `npx serve src`
ou Live Server). Não há build — os .jsx são transpilados no browser. ISSO É SÓ
PARA O PROTÓTIPO; em produção use JSX compilado normalmente.

CONVENÇÃO IMPORTANTE (Babel multi-arquivo): cada <script type="text/babel"> tem
escopo próprio. Por isso cada arquivo exporta seus símbolos com
`Object.assign(window, { ... })` no final, e os demais os consomem via window.
Ao portar para um bundler real, troque isso por imports/exports ES normais.

5. COMPORTAMENTO RESPONSIVO (tudo via media queries em styles.css)
================================================================================
REGRA DE OURO que já está aplicada e DEVE ser mantida ao editar: colunas de grid
flexíveis usam minmax(0, 1fr) — NUNCA 1fr puro — para poderem encolher abaixo do
conteúdo. Textos longos (títulos, URLs, @handle) usam
whiteSpace:nowrap; overflow:hidden; textOverflow:ellipsis + minWidth:0 no pai
flex. Esquecer isso causa overflow horizontal (cards "cortados").

Breakpoints:
  <=1100px  KPIs 4 -> 2 colunas
  <=1000px  Portfólio 3 -> 2 colunas
  <=860px   Sidebar some -> BOTTOM NAV fixo; grids de 2col (Analytics/Links/
            Detalhe do lead) -> 1col; colunas sticky deixam de grudar;
            .app-scroll ganha padding-bottom 64 + overflow-x:hidden
  <=680px   Tabela de Leads -> CARDS empilhados (header some; .lead-row usa
            grid-template-areas; células .lc-* reposicionadas/ocultadas)
  <=560px   KPIs/Portfólio/form do Perfil em 1col; topbar com altura automática

Padrões de implementação:
  - BottomNav (shell.jsx) renderiza sempre; CSS esconde no desktop e mostra
    <=860px; .app-sidebar faz o inverso.
  - Tabs (ui.jsx) têm overflow-x:auto + scrollbar oculta p/ rolar na horizontal.
  - Tabela->cards é 100% CSS (grid-template-areas + classes lc-lead/lc-status/
    lc-value/lc-date/lc-source/lc-chev).
  - env(safe-area-inset-bottom) no bottom nav (notch iOS).
